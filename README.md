# Sentiment Sense Frontend

A modern React-based frontend for a real-time multimodal sentiment analysis system.

## 🚀 Features
- Real-time text sentiment analysis
- YouTube comment analysis
- Reddit discussion analysis
- Image emotion detection
- Video emotion detection
- Live webcam emotion detection

## 🧠 Tech Stack
- ReactJS
- Custom CSS
- FastAPI backend integration
- REST APIs + WebSockets

## 📊 Architecture
Frontend communicates with FastAPI backend for processing text, image, and video inputs, and displays results using charts and visualizations.

## ⚙️ Setup

```bash
npm install
npm start
```
